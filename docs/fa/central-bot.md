# راهنمای بات مرکزی CYBRIX (@like_cybrixbot)

## دستورات عمومی
| دستور | کار |
|---|---|
| `/start` | شروع، بررسی عضویت کانال‌های اجباری، منوی اصلی |
| `/panel` | کد ورود ۵ دقیقه‌ای به پنل وب |
| `/wallet` | موجودی + ۱۰ تراکنش آخر |
| `/redeem CODE` | فعال‌سازی کد هدیه |
| `/mychannels` | کانال‌های ثبت‌شده شما |
| `/create` | ویزارد ساخت چالش (نیازمند کانال ثبت‌شده) |
| `/mystats` | آمار شخصی |
| `/support` | ارسال تیکت پشتیبانی (متن بعد از دستور) |
| `/lang` | تغییر زبان فارسی/English |
| `/help` | راهنما |
| `/cancel` | لغو ویزارد جاری |

## ساخت چالش (۴ نوع در نسخه ۱)
1. **🎲 قرعه‌کشی تصادفی** — همه واجدان شرایط وارد می‌شوند؛ برندگان با hash(salt:tid) صعودی انتخاب و با commit/salt/snapshot قابل راستی‌آزمایی عمومی اعلام می‌شوند.
2. **🗳 رأی‌گیری/لایک** — شرکت‌کننده‌ها گزینه می‌سازند؛ هر کاربر یک رأی (با اجازه تنظیم، قابل تغییر).
3. **👥 رقابت دعوت** — لینک اختصاصی؛ فقط دعوت‌های معتبر (یکتا + عضویت اجباری) شمرده می‌شوند.
4. **🧠 آزمون** — سؤال‌ها با فرمت `سؤال | گزینه۱ | گزینه۲ | #شماره‌درست` در ویزارد وارد می‌شوند.

مراحل ویزارد: نوع → عنوان → توضیح → کانال مقصد → زمان پایان (تهران) → تعداد برندگان → جوایز → پیش‌نمایش + هزینه → تأیید و انتشار.

هزینه‌ها (اعتبار): random=1، vote=2، referral=2، quiz=3. هر کاربر جدید ۱۰ اعتبار رایگان می‌گیرد.

## نکات مهم
- قبل از انتشار، بات دسترسی ارسال پیام به کانال را می‌سنجد؛ اگر نبود، هزینه برنمی‌گردد چون اصلاً کسر نمی‌شود و پیام راهنما می‌دهد.
- پایان چالش خودکار (هر ۵ دقیقه) + یادآوری ۱ ساعت قبل.
- مدیر کانال باید خودش ادمین همان کانال باشد و بات هم ادمین با اجازه ارسال پیام.

## دستورات مالک
`/stats` آمار کل · `/broadcast` اعلان همگانی · `/grant <tid> <amount>` شارژ دستی · `/gencode <amount> <uses>` کد هدیه · `/tickets` تیکت‌های باز · `/reply <id> <text>` پاسخ تیکت
